朝刊 / OpenAI / Skills

openai/skills は VTDD のドリフト対策に直結する

Skill は agent を強くするだけでなく、やってよいこと、やってはいけないこと、検証順序を固定して脱線を減らすために使えます。

VTDD への影響
mac Codex、VPS Codex CLI、Dashboard Butler が同じ前提を読むため、repo-backed skill と startup preflight の整備が重要です。
用語
Skill: 特定責務のための手順書。Subagent: 役割を分けた実行担当。Runtime truth: 現在の実行基盤が返す事実。

昼刊 / Dashboard / PWA

PWA通知はニュースにも使えるが、クリック先は Dashboard に戻す

iOS PWA の Web Push は外部サイト直行よりも、同一originの Dashboard news に戻す方が復帰と既読管理を安定させやすいです。

VTDD への影響
朝刊・昼刊・夕刊の通知は Dashboard Butler の通知センターに集約し、記事本体は Pages 側に置けます。
用語
Same-origin: 同じ scheme / host / port の範囲。PWA通知クリック時の復帰先を安全に制限しやすい。
